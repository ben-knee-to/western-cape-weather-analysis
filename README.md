# Western Cape Historical Weather Analysis

## Project Overview

The **Western Cape Historical Weather Analysis** project explores historical weather patterns across five locations in South Africa's Western Cape province: Cape Town, Stellenbosch, George, Worcester, and Knysna.

Using Python and interactive data visualisation tools, the project aims to identify temperature trends, rainfall patterns, seasonal variations, and differences in weather conditions between locations over a 16-year period.

The project includes a data collection pipeline, data quality validation, data cleaning, exploratory analysis, and an interactive Streamlit dashboard.

## Objectives

- Collect historical daily weather data for five Western Cape locations.
- Clean and validate the dataset for reliable analysis.
- Analyse temperature, precipitation, humidity, sunshine duration, and wind speed.
- Compare seasonal and annual weather patterns across locations.
- Build an interactive dashboard to communicate findings through visualisations.
- Demonstrate practical skills in data acquisition, data preparation, exploratory data analysis, and dashboard development.

## Dataset

Historical daily weather data is retrieved from the [Open-Meteo Historical Weather API](https://open-meteo.com/en/docs/historical-weather-api).

**Coverage:** 1 January 2010 to 31 December 2025.

**Locations:**
- Cape Town
- Stellenbosch
- George
- Worcester
- Knysna

### Variables

| Variable | Description | Unit |
|---|---|---|
| `date` | Date of observation | Date |
| `temperature_2m_mean` | Mean daily temperature at 2 metres | °C |
| `temperature_2m_max` | Maximum daily temperature at 2 metres | °C |
| `temperature_2m_min` | Minimum daily temperature at 2 metres | °C |
| `precipitation_sum` | Total daily precipitation | mm |
| `sunshine_duration` | Daily sunshine duration | Seconds |
| `wind_speed_10m_max` | Maximum daily wind speed at 10 metres | km/h |
| `relative_humidity_2m_mean` | Mean daily relative humidity at 2 metres | % |
| `location` | Location name | Text |
| `latitude` | Location latitude | Decimal degrees |
| `longitude` | Location longitude | Decimal degrees |

The downloaded dataset contains **29,220 rows and 11 columns**, with 5,844 daily records per location. Initial data quality checks reported no missing values or duplicate location-date records.

## Getting Started

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd Weather_Analysis
```

Replace the placeholder with your GitHub repository URL.

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it on Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Download the weather data

Run:

```bash
python fetch_weather.py
```

This retrieves the historical weather data and saves it to:

```text
data/western_cape_weather_2010_2025.csv
```

An internet connection is required to access the API.

### 5. Clean the dataset

Run:

```bash
python clean_weather.py
```

This prepares the cleaned dataset for analysis and saves it to:

```text
data/western_cape_weather_cleaned.csv
```

### 6. Launch the dashboard

After the cleaned dataset has been generated, run:

```bash
streamlit run app.py
```

Streamlit will provide a local URL where the dashboard can be viewed in your browser.

## Planned Dashboard Features

The dashboard is intended to include:

- **Weather overview:** key summary statistics for the selected locations and period.
- **Temperature trends:** annual average temperatures and daily temperature comparisons.
- **Rainfall analysis:** monthly precipitation patterns and annual rainfall totals.
- **Seasonal analysis:** comparisons across summer, autumn, winter, and spring.
- **Location comparisons:** differences in temperature and weather conditions between the five locations.
- **Wind and sunshine analysis:** exploration of wind speeds and sunshine duration.
- **Data explorer:** filtered records and downloadable CSV data.

## Data Quality and Methodology

The pipeline is designed to separate raw data collection from data cleaning and visualisation.

Initial checks on the downloaded dataset confirmed:
- 29,220 total records.
- Five locations represented.
- No missing values in the downloaded columns.
- No duplicate location-date records.

Further validation and cleaning are performed separately. These checks help identify invalid measurements, inconsistent temperature values, and other issues that could affect analysis.

Weather observations are location-specific and should not be interpreted as direct measurements for every part of the Western Cape. The project uses selected locations to explore and compare local weather patterns.
